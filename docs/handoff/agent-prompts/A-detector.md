# Package A — ring buffer + stutter detector (default model)

ASSIGNED SCOPE (only these paths): `src/Jankscope.Frames/Ring/*`, `src/Jankscope.Frames/Detection/*`, `tests/Jankscope.Frames.Tests/Ring/*`, `tests/Jankscope.Frames.Tests/Detection/*`, `tests/Jankscope.Frames.Tests/EndToEnd/*`.
Test-plan rows: 1, 2, 8 (`docs/test-plans/stage-1a.md`).

REQUIREMENTS
1. `RingBuffer<T>` (T is a struct): fixed capacity, overwrites oldest, ONE writer + MANY concurrent readers, `Write`/`TryWrite`, `Count`, `Capacity`, `long TotalWritten`, `CopyLatest(Span<T>)` / a snapshot API returning consistent (never torn) data; allocation-free write path (prove with `GC.GetAllocatedBytesForCurrentThread` deltas after warm-up); helpers for pre-roll window selection (last N items, and for `FrameSample`: items within a time window). Concurrency stress test (1 writer, 3 readers, >= 2 s) proving no torn reads (writer stores records whose fields satisfy an invariant; readers verify it).
2. `StutterOptions` (RollingWindowMs=1000, Multiplier=2.0, MinExcessMs=4.0, MinHistoryFrames=10, ClusterGapMs=500, Calibrated=false), `StutterEvent` (FrameIndex, TimestampMs, FrameTimeMs, MedianMs, ExcessMs, Ratio, Severity), `StutterDetector` with a batch API over `ReadOnlySpan<FrameSample>` and a streaming API (`Push(FrameSample)`) producing identical results. Definition (docs/METRICS.md): a frame is a stutter if `FrameTimeMs >= Multiplier × median(FrameTimeMs of the frames in the preceding RollingWindowMs, excluding the current frame)` AND `FrameTimeMs − median >= MinExcessMs`. With fewer than MinHistoryFrames preceding frames the status is "insufficient history" (counted), NEVER "no stutter". Outliers are never silently dropped (hitch frames stay in later windows; the median is robust). Reject non-finite/negative frame times with an explicit count + reason, not an exception. The result carries events, insufficient-history count, rejected count/reasons, a copy of the Calibrated flag (uncalibrated results are labelled so downstream grade caps apply), clustering (events closer than ClusterGapMs grouped) and a documented severity classification. Efficient (O(n log w) or better) and no per-frame allocation in the streaming path (order-statistics structure, two heaps, or a sorted window). Tests: exact boundaries (exactly 2× and exactly +4 ms must BOTH hold; 1.99× fails; +3.9 ms fails), warm-up, constant series → zero events, single spike, a low-average-FPS series with no spikes → zero events, clustering, batch == streaming for seeded random series, mutation check (change the multiplier logic → tests fail).
3. `GroundTruthMatcher.Match(IReadOnlyList<Jankscope.Core.InjectedHitch> injected, IReadOnlyList<StutterEvent> detected, int toleranceFrames, StutterOptions options, double baseFrameTimeMs)`: classify each injected hitch as Detected (within ±toleranceFrames), Missed, or NotDetectableByDefinition (the extra time is too small for the detector's thresholds to ever flag; compute from options and baseFrameTimeMs); count false positives; report precision/recall.
4. End-to-end test (pure, no Direct3D): for seeds 1..12 × fps {60, 144, 240} × hitch extra {15, 25, 50} ms × jitter {0, 0.3} ms, generate `Jankscope.Core.SyntheticWorkload` runs, convert to `FrameSample`s (cumulative timestamps), run the detector and assert: every detectable injected hitch is found within ±1 frame, zero false positives on clean runs (0 hitches, with and without jitter), sub-threshold hitches reported as NotDetectableByDefinition. If some combination cannot meet the exit criterion, report precisely which and why — do NOT weaken the definition silently.

Rules reminder: `src/Jankscope.Frames` has no native imports and must stay free of banned APIs (see COMMON.md); a ring buffer and detector need only managed code.

Note for the integrator: `SyntheticWorkload` now uses its own SplitMix64 generator and validates inputs (jitter must be below the base frame time).
