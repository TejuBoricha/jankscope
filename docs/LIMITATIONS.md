| L22 | PresentMon launch path | The child is created from the file's path, not from the verified handle. | L24 | How the child is ended | `Process.Kill()` on the child only; no process tree is walked, because the tree form makes the runtime open a handle to every process on the machine (found in Stage 1a review #1, from the runtime's IL; not observed at run time because that needs a system audit-policy change). The set of `Process` members the launcher may use is pinned by `LauncherLintTests`. | Stage 1a review (#1) | If tree semantics are ever needed use a Job Object (3 imports) and say so here |

| L28 | Executable path check | A mapped network drive or a `subst` drive letter passes as "local"; an on-demand cloud placeholder (a reparse point) is refused as a link. The path is not compared with the resolved final path. | Stage 1a review (#17) | Compare with the resolved final path |
| L29 | Short user/host names in free text | How a known value (this PC's user name, PC name, ...) is matched depends on where the string sits (`Redactor`, `KnownValueMode`, mirrored by `ExportGuard`): in the note and the program name (property names `note`, `targetProcess`, ... ) a name of 2 or more characters is matched anywhere in the string, so `maria225` or `mymaria` do not survive; in this tool's own string values from 4 characters; in JSON property names from 6 characters (shorter names whole-word only, so the fixed schema is not renamed); a name in Chinese, Japanese, Korean or Thai is always matched as a substring; names are compared after Unicode normalisation (NFC). Still not caught: a 1-character name, a 2 or 3 character name glued to other letters in this tool's own prose (such a name is only removed as a whole word there), a user name that is an ordinary word renames a schema key that equals it (`mark`), and values Jankscope does not know (an SSID, a serial, a name that is not this PC's user name) typed into a note. IPv4 addresses and MAC addresses (with `:`, `-`, `.` or no separator, the last only when it contains a letter) are found by shape even when letters, digits or underscores touch them. Structured profile paths, UNC hosts and OneDrive paths are always redacted regardless of length. | Stage 1b (independent review finding 2) | The export dialog and the welcome screen say that only what Jankscope knows about is removed and that the note must be read; the shipped dialog does not list the remaining gaps |
