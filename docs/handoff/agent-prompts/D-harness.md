Output (`--out FILE`): a CSV using PresentMon 2.6.0 column names for the columns you can truthfully provide (`Application,ProcessID,TimeInMs,MsBetweenPresents,…`, literal `NA` for the rest) plus a JSON summary, everything tagged Simulated (never exportable as a measurement). Modes: keep `plan`; add `run --seed N --fps F --frames N --hitches N --extra-ms M --jitter-ms J --out FILE [--adapter auto|hardware|warp] [--window-visible]`; good `--help`. Unelevated; exits cleanly (dispose device, swap chain, window). Do not use `timeBeginPeriod` or other timer-resolution hacks unless proven needed; document the choice.

TESTS (`[Trait("requires","d3d")]`, skipped WITH A REASON via your own conditional Fact attribute when no D3D11 device can be created): schedule fidelity (report max / median / p99 error in ms and assert a justified tolerance), hitch frames carry the injected extra within tolerance, schedule determinism, forced `--adapter warp`, CSV schema (column names exactly as in the fixture README), Simulated tagging, and that no output claims to be a measurement.
