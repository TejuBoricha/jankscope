# Package B1 — PresentMon CSV parser (default model)

READ ALSO: `docs/FACTS.md` (F11–F14), `tests/fixtures/presentmon/README.md`, the real fixture `tests/fixtures/presentmon/v2.6.0-real-sanitized.csv` (857 rows), `src/Jankscope.Frames/{FrameSample,IFrameLogParser}.cs`.

ASSIGNED SCOPE (only these paths): `src/Jankscope.Frames/PresentMon/PresentMonCsvParser.cs` (plus small private helpers in that folder whose names start with `Csv`), `tests/Jankscope.Frames.Tests/PresentMon/CsvParser*Tests.cs`, extra fixtures `tests/fixtures/presentmon/synthetic-*.csv`. Test-plan row 3.

REQUIREMENTS: implement `IFrameLogParser` as `PresentMonCsvParser`. The real PresentMon 2.6.0 header has 28 columns (see the fixture README). Columns are identified by NAME, case-insensitive, order-independent. Required for support: a frame-time column (`MsBetweenPresents` in 2.x; `msBetweenPresents` in 1.x) and a timestamp column (`TimeInMs` in 2.x; `TimeInSeconds` in 1.x, converted to ms); if missing → `Supported=false` with an `UnsupportedReason` naming the missing column(s). Optional columns mapped when present: `MsBetweenDisplayChange`/`msBetweenDisplayChange` → `DisplayedFrameTimeMs`; `MsCPUBusy` → `CpuBusyMs`; `MsGPUBusy` → `GpuBusyMs`; `PresentMode`; `Application`; `ProcessID`. Unknown columns → `IgnoredColumns`; absent optional columns → `MissingOptionalColumns`. The literal `NA` (and empty) → null, never 0. `<unknown>` application text is kept. Format detection PresentMon2 vs PresentMon1 (`--v1_metrics` header begins `Application,ProcessID,SwapChainAddress,Runtime,SyncInterval,PresentFlags,AllowsTearing,PresentMode,Dropped,TimeInSeconds,msInPresentAPI,msBetweenPresents,msBetweenDisplayChange,msUntilRenderComplete,msUntilDisplayed` — build a synthetic v1 fixture from this and label it synthetic); Format=PresentMon1 tells downstream that 1.x metrics are not comparable with 2.x. Handle quoted fields with commas and doubled quotes. Parse numbers with the invariant culture (test under de-DE and tr-TR thread cultures). Never throw on malformed input: `TryParseRow` returns false plus a problem string (wrong field count, non-numeric required value, negative/NaN/infinite frame time, truncated last line). Rows get sequential Index. Also provide `PresentMonCsv.ReadAll(TextReader, out LogHeaderResult header, out IReadOnlyList<string> problems)` and a streaming `IEnumerable<FrameSample>` variant that does not load the file into memory (test with a generated 1,000,000-row stream within a justified time/memory bound).

TESTS: the real fixture parses all 857 rows with first/last values computed from the CSV text inside the test; reordered / extra / missing-column fixtures; the v1 fixture; NA handling; `MsBetweenPresents` vs `MsBetweenDisplayChange` never merged; truncated line; UTF-8 BOM; CRLF and LF; blank lines; unsupported-header reason text; mutation check (map the wrong column → tests fail); a plausibility test that `Jankscope.Core.FrameStats.AverageFps` over the real fixture's frame times is consistent with the ~6.4–7.0 ms between presents seen in the log — without hardcoding a number you cannot justify.
